# Почта столиц

Игра-тренажёр столиц всех стран мира со смешными ассоциациями.

- Раунды: тест, наоборот, письмо, карточки
- Цель дня, серия дней, паспорт с марками
- Онлайн-батл до 6 игроков по ссылке (очки за скорость)
- Обмен ассоциациями по ссылке, перенос прогресса

Играть: https://viktorvartanov.github.io/pochta-stolic/
